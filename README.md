# فیلکس | Feelks

وب‌سایت فارسی، راست‌به‌چپ و تک‌صفحه‌ای فیلکس با HTML، CSS و JavaScript ساخته شده است. اجرای سایت به نصب وابستگی یا مرحلهٔ build نیاز ندارد. انتشار عمومی و اتصال دامنه انجام نشده است.

نشانی پیش‌نمایش خصوصی: https://feelks-preview.shhbsaremi.chatgpt.site — ورود با حساب مالک لازم است. وضعیت انتشار آخرین ویرایش جداگانه اعلام می‌شود؛ وجود این نشانی به معنی انتشار تغییرات محلی جدید نیست.

مرجع پرینتیا از طریق HTML و محتوای متنی بررسی شد؛ بررسی بصری کامل آن انجام نشد. ساختار مستقل سایت از فضای سفید، کارت‌های منظم و گوشه‌های گرد استفاده می‌کند. هویت فعلی بر پایهٔ لوگوی اصلی، پالت و فونت‌های ارسالی برند است: `#ffcd00`، `#939598`، `#505759`، `#231f20` و `#f3f0e6`. فونت اصلی Alibaba در سه وزن به‌صورت محلی بارگذاری می‌شود.

## اجرا

در پوشهٔ پروژه اجرا کنید:

```bash
python -m http.server 8080 --directory dist
```

سپس `http://localhost:8080` را باز کنید. تمام فایل‌های اجرایی در `dist` قرار دارند؛ برای جابه‌جایی یا میزبانی، این پوشه را با ساختار کامل کپی کنید. فایل‌های خام `source-assets`، ابزارهای `tools` و خروجی‌های `artifacts` برای اجرای سایت لازم نیستند.

## محل ویرایش محتوا

| فایل | کاربرد |
| --- | --- |
| `dist/config.js` | لوگو، رنگ‌های اصلی، تصاویر معرفی خدمات، شمارهٔ واتساپ، اطلاعات تماس، حساب و عکس‌های اینستاگرام |
| `dist/content.js` | متن سه خدمت، مزیت‌ها، مسیر همکاری، پرسش‌ها و آرایهٔ دیدگاه‌های تأییدشده |
| `dist/projects.js` | پروژه‌های هر خدمت، اقدامات واقعی، نوع همکاری و رسانه‌های هر پروژه |
| `dist/partners.js` | نام و مختصات نمایش نشان‌های فایل اصلی همکاران |
| `dist/index.html` | سربرگ، آغاز صفحه، بخش‌های ثابت، فرم و اطلاعات سئو |
| `dist/styles.css` | چیدمان، واکنش‌گرایی، پالت تکمیلی و فونت‌های محلی |
| `dist/app.js` | نمایش خدمات و پروژه‌ها، منوی موبایل، گالری رسانه و ساخت پیام واتساپ |
| `dist/engagement.js` | مرور افقی دیدگاه‌ها و گالری اینستاگرام |
| `dist/assets/` | تصاویر بهینه، لوگوها، فونت‌ها و مجوز فونت Vazirmatn |

شمارهٔ واتساپ تأییدشدهٔ برند، `+989383888636`، در `whatsapp.number` تنظیم شده است. ایمیل، آدرس و شمارهٔ تماس مستقل در `contact` خالی‌اند و نمایش داده نمی‌شوند. اینستاگرام روی `feelks.cafe` تنظیم شده است. در صورت تغییر رنگ اصلی یا لوگو، `theme-color`، نشان مرورگر و پیش‌بارگذاری‌های `index.html` را نیز هماهنگ کنید.

لینک‌های مستقیم: `#services`، `#workplace`، `#cafe`، `#events`، `#experience`، `#process`، `#faq`، `#instagram` و `#contact`. شناسه‌های سه خدمت را ثابت نگه دارید؛ پروژه‌ها، فرم و دیدگاه‌ها از همین شناسه‌ها استفاده می‌کنند.

## تجربه‌ها و رسانه‌ها

تصاویر اولیهٔ بخش آغازین و معرفی سه خدمت، همان چهار تصویر عمومی Unsplash هستند و نمونه‌کار واقعی فیلکس محسوب نمی‌شوند. توضیحات نمایشی منبع از صفحه حذف شده‌اند؛ منشأ آن‌ها همچنان در `ASSETS.md` ثبت است.

سه کلاژ واقعی ارسالی برند برای کافهٔ دیجی‌پی، رویداد دیجی‌پی و رویداد دانشگاه توانبخشی، با حفظ تمام ترکیب تصویر به WebP تبدیل شده‌اند. دکمهٔ «تجربیات» در هر خدمت، پروژه‌های همان خدمت را نشان می‌دهد. انتخاب پروژه، متن و رسانه را تغییر می‌دهد؛ «بازگشت به معرفی خدمت» محتوای اصلی را برمی‌گرداند. پیش‌نمایش با ماوس فقط رسانه را موقتاً تغییر می‌دهد؛ در موبایل انتخاب با لمس انجام می‌شود.

برای افزودن پروژه، یک رکورد به آرایهٔ خدمت مربوط در `projects.js` اضافه کنید. `id` باید یکتا باشد. `title` و `description` معرفی پروژه، `items` اقدامات واقعی و `collaboration` نوع همکاری‌اند. اطلاعات نامشخص را نسازید: در دو پروژهٔ رویدادی فعلی، اقدامات و نوع همکاری هنوز تکمیل نشده و صفحه همین وضعیت را بیان می‌کند. برای کافهٔ عمومی هنوز پروژه‌ای ثبت نشده است.

آرایهٔ `media` هر پروژه می‌تواند چند رسانه داشته باشد:

| فیلد | کاربرد |
| --- | --- |
| `type` | `image` یا `video` |
| `src` | مسیر محلی فایل بهینه در `assets/projects` |
| `alt` | توضیح واقعی و کوتاه رسانه |
| `poster` | تصویر پیش‌نمایش اختیاری ویدئو |
| `captions` | مسیر اختیاری زیرنویس فارسی ویدئو با قالب WebVTT |

هیچ ویدئویی از برند دریافت یا منتشر نشده است. پشتیبانی ویدئو در کد آماده است: کنترل پخش دارد، خودکار پخش نمی‌شود و در ابتدا بی‌صداست. جابه‌جایی رسانه، بستن نمایش بزرگ یا مخفی‌شدن صفحه، ویدئو را متوقف می‌کند.

نشان‌های همکاران از PNG اصلی و بدون تغییر آن نمایش داده می‌شوند؛ `partners.js` محدودهٔ هر نشان را برای SVG `viewBox` مشخص می‌کند. نشان پنجم نام قابل تشخیصی ندارد و برچسب عمومی گرفته است؛ نام تجاری برای آن حدس نزنید.

## دیدگاه‌ها و اینستاگرام

فایل ارسالی `تستمونیال.jpg` فقط مرجع چیدمان است. فرد و نقل‌قول نمونهٔ داخل آن به‌عنوان مشتری واقعی منتشر نشده‌اند. `content.testimonials` فعلاً خالی است و سه جایگاه بدون شخص یا نقل‌قول ساختگی نمایش داده می‌شود. برای انتشار دیدگاه واقعی، پس از دریافت اجازه، رکوردی با `service`، `quote` و اطلاعات تأییدشدهٔ `name`، `role`، `company` و در صورت وجود `image` اضافه کنید.

دریافت عکس از صفحهٔ عمومی اینستاگرام به‌دلیل محدودیت پاسخ سرویس ممکن نشد؛ `config.instagram.photos` خالی است و فقط پیوند حساب نمایش داده می‌شود. عکس نامرتبط جایگزین نشده است. عکس‌های منتخب همان حساب را به‌صورت محلی بهینه و با فیلدهای `src`، `alt` و پیوند اختیاری پست در `href` اضافه کنید. گالری آمادهٔ حرکت پیوستهٔ افقی، توقف با دکمه، ماوس و فوکوس، پیمایش لمسی و رعایت تنظیم کاهش حرکت است؛ سایت دریافت خودکار از اینستاگرام انجام نمی‌دهد.

## فرم و واتساپ

فرم فعال است و دکمهٔ آن «ادامه در واتساپ» است. نام و نام خانوادگی، شمارهٔ تماس و نوع خدمت اعتبارسنجی می‌شوند؛ نام مجموعه و توضیح نیاز اختیاری‌اند. شماره‌های فارسی، عربی و انگلیسی، شمارهٔ ثابت یا همراه ۱۱ رقمی ایران و پیش‌شماره‌های `+98` و `0098` پذیرفته و به شکل `0…` تبدیل می‌شوند.

فرم، نام، شماره، شرکت، خدمت، توضیحات و در صورت انتخاب، پروژهٔ مورد اشاره را به پیش‌نویس پیام تبدیل می‌کند. دکمه‌های عمومی، خدمت و پروژه نیز لینک `wa.me` با متن متناسب دارند. انتخاب دکمهٔ خدمت یا پروژه، زمینهٔ همان مورد را برای فرم نگه می‌دارد؛ با تغییر خدمت یا دکمهٔ حذف می‌توان زمینهٔ پروژه را پاک کرد.

با بازکردن لینک، متن پیش‌نویس به واتساپ منتقل می‌شود؛ ارسال نهایی را خود مشتری در واتساپ انجام می‌دهد. سایت ادعای ارسال یا ثبت موفق ندارد و برای فرم از backend، `fetch` یا ذخیره‌سازی مرورگر استفاده نمی‌کند. اتصال سرویس دریافت فرم برای این روش لازم نیست. اگر مرورگر پنجرهٔ جدید را مسدود کند، پیوند بازکردن پیش‌نویس در پیام زیر فرم باقی می‌ماند.

## بررسی ویرایش‌ها

پس از اجرای وب‌سرور محلی، می‌توان از پوشهٔ پروژه اجرا کرد:

```bash
python artifacts/update-qa.py http://127.0.0.1:8080/
```

این ابزار توسعه به بستهٔ Python Playwright و مرورگر Chromium در `/usr/bin/chromium` نیاز دارد؛ این وابستگی‌ها برای اجرای خود سایت لازم نیستند. خروجی در `artifacts/update-qa.json` و تصاویر همان پوشه قرار می‌گیرد. نتیجهٔ آخرین اجرای ابزار، ملاک وضعیت بررسی همان نسخه است؛ این راهنما به‌تنهایی قبولی ویرایش جدید را اعلام نمی‌کند.

ابزار، اندازه‌های مختلف، منو، لینک‌ها، انتخاب و بازنشانی پروژه، فرم و زمینهٔ پیام واتساپ را بررسی می‌کند و پیام واقعی نمی‌فرستد. آزمایش‌های گالری چندرسانه‌ای و اینستاگرام پرشده، دادهٔ موقت فقط داخل مرورگر دارند؛ این داده‌ها در سایت منتشر نمی‌شوند. ویدئوی آزمایشی احتمالی در `artifacts` نیز رسانهٔ واقعی برند نیست.

نتیجهٔ بررسی نسخهٔ اصلاح‌شده در `VERIFICATION.md` ثبت شده است. موارد محتوایی باقی‌مانده و مراحل انتشار عمومی در `RELEASE-CHECKLIST.md` آمده‌اند.
